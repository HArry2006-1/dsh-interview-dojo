# 面试道场 / Interview Dojo

日本留学面试的**实时语音模拟练习**插件：按“目标大学与专业 → 入学理由书 → 生成资料”三步填写，插件会检索学校官网资料，生成“共通题型 + 本校专属题型 + 理由书追问”的题库，然后用日语与你进行带反馈的模拟面试。

每轮对话都保留：

- 日语原文 + 中文翻译
- 面试官意图、回答结构、文化与礼仪提示
- 重难词汇（词形、读音、中文、级别、例句）并在日语原文中高亮
- 语法/句型解析
- 参考回答（日语 + 中文）
- 对你回答的评分、优点、改进点、日语修正和内容建议

## 30 秒安装与开始

1. 解压 `dsh-interview-dojo-0.1.0.zip`，得到 `dsh-interview-dojo/` 文件夹。
2. 在 DSH 打开「设置 → 插件」，使用「添加插件 / 安装本地插件」，选择该文件夹；安装后刷新页面。
3. 打开任意一个会话，点击对话主区域上方的 **「面试道场」** 标签（或右侧栏「+」→「面试道场」）。
4. 第一次使用直接点 **「填入示例试试看」**，按 1 → 2 → 3 走一遍，再替换成自己的大学、专业和理由书。

需要先配置好 LLM 与网页搜索/抓取；语音识别依赖浏览器，或使用 DSH 已准备好的本机 SenseVoice。自然语音（Edge 在线）是可选增强；没有安装时会自动使用系统语音，免提对话不受影响。

## 打开方式

安装并启用插件后，有三种入口：

1. **对话主区域上方的「面试道场」标签**（最容易找到；适合全宽使用）
2. 右侧栏顶部 **「+」→ 指南页「面试道场」**
3. 输入框右侧的 **「面试道场」** 小按钮
4. **设置 → 面试道场**（专门的使用说明页，可从那里打开右侧栏）

**如果点进去是空白：** 先刷新一次 DSH 页面（新安装的浏览器端需要重新加载）；然后从对话主区域上方的「面试道场」标签进入。仍空白时，到「设置 → 插件」确认「面试道场」已启用，并把错误信息反馈给作者。

## 使用流程

进入后按页面顶部的 **1 → 2 → 3** 步骤操作，每一步都有独立区域和按钮：

1. **目标大学与专业**：目标大学（必填）、学部/研究科、专业/专攻、课程、面试形式、日语水平、官网 URL（可选）。不知道填什么可以点「填入示例」。
2. **放入入学理由书**：在独立的上传区选择 `.txt` / `.md` / `.docx` / `.pdf`，或直接在下方粘贴/编辑正文。PDF 为文本抽取，扫描件或使用 CID 字体编码的日文 PDF 可能无法完整还原，此时请手动粘贴/修正。
3. **生成面试资料与题库**（会消耗搜索与模型额度）：点主按钮后，插件会：
   - 用 `ctx.web.search` 搜索该大学的留学生入试、招生理念、募集要项等页面；
   - 只保留官网域名内、最多 7 个页面的正文；
   - 把公开资料和你填写的理由书交给当前模型，生成大学画像、面试重点和预测题。
4. **确认资料并开始模拟面试**：先检查大学画像、题目池和来源，再开始。面试官一次只问一个问题。你可以：
   - **文字回答**：输入日语或中文，模型会尽量理解并反馈；
   - **免提语音对话**（默认开启）：面试官用自然日语朗读完问题后，插件会**自动开始听**，直接说日语即可；浏览器识别停顿约 3 秒自动提交，本机 SenseVoice 用静音检测约 3 秒自动结束。面试官下一题朗读完后又会自动开始，不需要每轮点麦克风。
   - **手动控制**：也可以随时点麦克风开始/结束；不想免提时在「语音设置」关闭「免提对话」。
5. **提示 / 结束**：卡住时点「提示」获得回答骨架和可用表达；结束后生成总分、优缺点、大学匹配度与下一步练习建议，可导出 Markdown 记录。

## 面试显示选项

面试中输入区上方的「显示选项」可以独立开关：

- **日文原文**：显示/隐藏面试官问题、开场、参考回答中的日文；
- **中文翻译**：显示/隐藏对应的中文翻译。

解析、词汇、语法、评分和中文建议仍保留；关闭日文不会关闭面试官语音。选项会记在本机，下次打开继续生效。

## 朗读：自然语音优先

面试官朗读可在「语音设置 → 朗读引擎」中切换：

1. **自然语音（Edge 在线，默认）**
   - 使用 Microsoft Edge 的神经语音，默认 **七海（ja-JP-NanamiNeural）**，也可选 **圭太（ja-JP-KeitaNeural）**。
   - 明显比系统语音自然，支持语速调节；音频由本机 Host 生成并缓存在 `tts/`，同一句再次朗读会很快。
   - 需要联网。语音请求会把**当前要朗读的日文问题文本**发送给 Microsoft Edge 语音服务；理由书正文本身不会专门发送给 TTS，但问题中可能包含由理由书生成的内容。
   - 需要可选依赖 `@andresaya/edge-tts`。若未安装或网络失败，会自动回退系统语音，不阻塞面试。
2. **系统语音（离线）**
   - 使用浏览器/系统的 `SpeechSynthesis` 日语语音包；音色取决于电脑安装的语音包，可能较机械。
   - 没有网络或不想把朗读文本发给在线服务时使用。

## 实时语音识别与免提

本插件提供两条识别路径，可在「语音设置 → 识别引擎」中切换：

1. **浏览器实时识别（默认优先）**
   - 使用 Web Speech API（`SpeechRecognition`，语言 `ja-JP`），边说边出识别结果。
   - 请使用 Chrome / Edge 等 Chromium 浏览器，并允许麦克风权限。
   - 识别可能是**在线服务**，音频可能发送给浏览器厂商；插件本身不保存音频。
2. **本机 SenseVoice 录音识别（兜底/隐私优先）**
   - 使用 DSH 已加载的本机 SenseVoice 模型（`ctx.speechToText`）转写。
   - 音频只在电脑本机处理，不离开设备；需要 DSH 中已准备好日语模型。
   - 自动模式下，如果浏览器识别报网络/服务错误，会切换到本机识别；免提会继续尝试自动开始录音。

免提工作方式：

- 默认开启。开始面试后，面试官朗读结束 → 自动开始听 → 停顿后自动提交 → 下一题朗读结束 → 再自动听，循环进行，不需要每轮点击。
- 第一次需要允许麦克风权限；浏览器自动播放策略也可能要求你点一次「朗读问题」来解锁声音，之后免提循环即可持续。
- 本机识别在免提时使用 Web Audio 静音检测：检测到说话后，连续约 3 秒安静就结束录音并转写；18 秒没听到声音会结束本次录音。
- 若关闭「识别完成后自动发送」，识别文字会留在输入框，避免误发；免提不会在输入框有文字时强行开始。
- 麦克风权限被拒绝、浏览器不支持、语音服务不可用或本机模型未就绪时，界面会给出具体提示，并始终保留文字输入路径。
- 即使不开语音模式，也可以点「朗读问题」听当前问题的日语读音。

## 存档与一键清空

练习结束后不需要逐个删除字段：

- **存档为 Word**：把本场完整记录保存成一份 Word 兼容文档并下载，同时在本机 `archives/` 留一份 `.doc` 和 `.md`。
- **下载 Markdown**：只下载可编辑的 Markdown 版本。
- **存档并新建**：先存档、下载，然后自动清空当前练习并回到空白的第一步。
- **清空并新建**：会弹出一次确认；确认后删除当前会话记录、清空目标大学/专业/理由书/题库，并写入“不要恢复上一场”的本机标记。`archives/` 里已经存过的文件不会被删除。
- 右侧栏或主区域顶部的 **「存档」/「清空」** 按钮在面试中也可用；面试报告页有完整的一组操作。

存档内容包含：

- 目标大学、学部/研究科、专业/专攻、课程、面试形式、日语水平、时间；
- 本次提交的入学理由书；
- 大学调研摘要、招生理念、面试重点、题库与来源；
- 开场、每一问的面试官问题/反应、你的回答、评分与改进、参考回答；
- 每题的重难词汇、语法表达、回答结构与文化提示；
- 最终面试报告；
- 汇总后的重难词汇与语法知识清单；
- “不是官方过去问”的免责声明。

存档文件位置：`%USERPROFILE%\.dsh\interview-dojo\archives\`（其他平台 `~/.dsh/interview-dojo/archives/`）。Word 文件是 Word/WPS 可直接打开的 `.doc`（HTML 内容）；如果需要原生 `.docx`，在 Word 中另存为即可。

## 分享给别人使用

- 共享包：`dsh-interview-dojo-0.1.0.zip`（与插件目录同一层），解压后得到 `dsh-interview-dojo/` 文件夹。
- 对方在 DSH 的「设置 → 插件」使用「添加插件 / 安装本地插件」，选择解压后的目录；安装后刷新页面。
- 对方也需要配置好 LLM 与网页搜索/抓取；语音识别依赖浏览器或 DSH 本机 SenseVoice。
- **自然语音是可选增强**：分享包里不附带 `@andresaya/edge-tts`。如对方环境安装了 `package.json` 的 optionalDependency，会自动使用；否则自动使用系统语音。
- 手动安装自然语音（在插件目录执行）：`pnpm add @andresaya/edge-tts@1.9.1`，然后重载插件。该依赖为 GPL-3.0，只作为独立可选组件动态加载，不随插件源码打包。
- 插件以本地链接方式安装；移动/删除该目录会导致插件失效。

## 配置要求

- DSH 已配置可用的 **LLM 模型**（研究阶段与每轮对话都会调用，消耗额度）。
- DSH 已配置 **网页搜索与抓取**（`ctx.web`）。没有搜索时，仍可填写官网 URL 直接抓取。
- 插件默认使用 DSH 的默认模型（`agentDefaultModel`）；在设置区可切换模型（同一模型目录内的模型）。
- **自然语音**需要联网；**系统语音**离线可用。语音识别需要浏览器麦克风权限；本机识别需要 DSH 已准备好 SenseVoice 日语模型。

## 数据与隐私

- 调研缓存和面试记录保存在：
  - Windows：`%USERPROFILE%\.dsh\interview-dojo\`
  - 其他平台：`~/.dsh/interview-dojo/`
- 子目录：`research/`（官网资料缓存）、`sessions/`（面试记录）、`tts/`（自然语音音频缓存，最多保留 100 个片段）、`archives/`（手动存档的 `.doc` 和 `.md`，最多保留约 100 份存档）。
- 「清空并新建」会删除当前 `sessions/` 会话文件，但不会删除 `archives/` 中已存档的文件。
- 存档文档包含理由书、回答和逐题解析，属于个人学习资料；下载后请自行保管。
- 理由书正文会：
  - 发送给当前配置的 LLM 以生成问题与反馈；
  - 保存在本机 session JSON 中，以便继续练习；
  - 在开始面试前也会缓存在浏览器 localStorage 中，方便继续编辑；
  - 不会上传到插件作者或额外第三方服务。
- 官网页面内容经 `ctx.web` 获取；大学名、搜索词会发送给已配置的搜索提供方。
- 浏览器语音识别可能联网；本机 SenseVoice 识别在本机完成。
- **自然语音（Edge 在线）**会把当前朗读的日文文本发送给 Microsoft 的 Edge 语音服务；音频缓存在本机 `tts/`。如果不想发送，请在「语音设置」改用「系统语音（离线）」。
- 系统语音由浏览器/系统的日语语音包提供，具体取决于本机安装的语音包。

## 重要限制

- 界面为中文；日语学习材料和语音为日语。
- **题库不是学校官方过去问。** 它由“常见日本留学面试题型 + 官网公开资料 + 理由书”经模型归纳生成，只用于练习。正式面试请以学校最新募集要项、入试要项和实际通知为准。
- 官网抓取只保留官网域名内最多 7 个页面，不解析 PDF 正文（遇到 PDF 会跳过），也不处理视频、登录页；网页结构差异会导致抓取失败或正文不完整。
- 模型可能生成不准确或过时的信息；大学画像中的“原文摘录”和来源列表也会受抓取质量影响。请用来源链接核对。
- 语音识别会受口音、环境噪声和浏览器服务影响；可随时改用文字输入。
- 自然语音依赖 Microsoft Edge 在线语音服务；服务不可用、网络受限或可选依赖未安装时会回退到系统语音，音色会变回本机语音包。
- 免提需要先允许麦克风权限；部分浏览器会阻止自动播放，此时点一次「朗读问题」即可解锁后续循环。本机免提的静音阈值受环境噪声影响，嘈杂环境可改用浏览器识别或手动麦克风。
- 存档的 Word 文件是 HTML 内容的 `.doc`，Word/WPS 可打开；如果学校要求提交原生 `.docx`，请打开后另存为 `.docx`。
- 清空操作只清除当前会话与当前练习字段，不会删除已经存档到 `archives/` 的文件；删除前仍会弹一次确认。
- 本插件不替代正式日语训练，也不保证面试结果。

## 开发与验证

纯函数部分可独立测试：

```bash
node --test test/*.test.js
node --check index.js
node --check client.js
```

核心代码：

- `index.js`：Host 半侧，HTTP 路由、LLM 调用、会话存储。
- `client.js`：浏览器半侧，主区域/右侧栏工作台、三步引导、聊天、显示开关、语音与解析渲染。
- `lib/extract.js`：TXT/MD/DOCX/PDF 抽取、HTML 正文与链接、宽松 JSON 解析。
- `lib/research.js`：官网发现与有界抓取。
- `lib/prompts.js` / `lib/schema.js`：提示词与模型输出归一化。
- `lib/llm-call.js`：通过 `ctx.llm` 流式生成并组装 JSON。
- `lib/store.js`：本地数据目录、调研缓存、会话持久化。
- `lib/tts.js`：可选 Edge 神经语音合成与本地音频缓存；依赖缺失时由客户端回退系统语音。
